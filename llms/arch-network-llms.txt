# Arch Network

> Bitcoin-native financial infrastructure and computation environment. Arch lets developers build
> DeFi and capital-markets applications — lending, yield, trading, and structured products — with
> settlement kept local to Bitcoin. It executes programmable smart contracts (written in Rust) over
> Bitcoin UTXOs using a specialized virtual machine and threshold-cryptography (FROST/ROAST)
> validator security, and exposes a JSON-RPC API with TypeScript and Rust SDKs, a CLI, and an AI
> agent kit.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public developer
surface and the API Evangelist catalog. Arch Network exposes a JSON-RPC (not REST/OpenAPI) API.

## SDKs & Tools

- [@arch-network/arch-sdk (npm)](https://www.npmjs.com/package/@arch-network/arch-sdk): TypeScript/JavaScript client for the Arch JSON-RPC API.
- [@arch-network/wallet-hub-sdk (npm)](https://www.npmjs.com/package/@arch-network/wallet-hub-sdk): TypeScript client for the Arch Wallet Hub API.
- [arch-sdk (Rust)](https://github.com/Arch-Network/arch-sdk): Rust SDK for building Arch Network programs.
- [arch-agent-kit](https://github.com/Arch-Network/arch-agent-kit): Plugin-based toolkit to connect AI agents to on-chain actions (wallet, Runes, data).
- [arch-cli (archived)](https://github.com/Arch-Network/arch-cli): Legacy CLI; latest CLI ships with arch-node releases.
